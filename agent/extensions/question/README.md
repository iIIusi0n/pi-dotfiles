# question

Registers the `question` tool: one question with a list of selectable options
plus an inline editor for a free-text "Type something" answer. Escape in the
editor returns to the options; Escape in the options cancels.

Vendored/adapted single-file extension; imports `@earendil-works/pi-coding-agent`,
`@earendil-works/pi-tui`, and `typebox`, all supplied by the Pi host.
